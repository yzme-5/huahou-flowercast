# 创新创业基础课程提交说明

## 作品名称

花候 FlowerCast——城市花境四季配置与低维护推演模型

## 对应成果层级

本项目属于“实际创新产出”，具备可打开、可操作、可解释和可交付的模型作品：

- GitHub 仓库：https://github.com/yzme-5/huahou-flowercast
- 在线作品：https://yzme-5.github.io/huahou-flowercast/
- 本地入口：`index.html`
- 导出成果：CSV 植物配置单或浏览器打印 PDF

## 与园艺专业的结合

作品把以下园艺专业知识转成程序规则：

- 观赏植物的光照、水分、土壤 pH 和耐寒区适应
- 花期连续性与常绿/观叶结构
- 前低后高、成组重复和形态穿插的配植方法
- 养护投入与景观复杂度之间的平衡
- 湿热、干冷和荫蔽场地的风险复核

## 建议提交方式

1. 在作业平台填写在线作品链接和 GitHub 仓库链接；
2. 上传仓库根目录中的 `docs/screenshots/01-homepage.png` 与 `02-model-result.png`；
3. 如需单一文件，在线页面选择“打印 / 保存 PDF”后提交；
4. 学习心得与商业计划书如课程另有要求，可分别提交独立文档。

## 展示路径建议

先用“半阴小阳台”预设展示完整结果；再切换“北方低水庭院”，观察推荐植物、生态指数和养护任务随之变化；最后展开一种植物的“匹配依据”，说明模型为何不是黑箱。

## 边界说明

这是课程原型，不是经过多年多地区田间试验的商业生产系统。植物区间、价格和养护估算需要当地苗圃与农技人员复核。
