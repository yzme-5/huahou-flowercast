# 实验与验收记录

## 自动化测试

执行：

```powershell
npm test
```

覆盖内容：

- 24 种植物记录完整性
- 光照匹配和相邻环境降级
- 城市耐寒区适配
- 3 组场景预设均可生成 6 类以上植物
- 12 个月季相与养护日历结构完整
- CSV 表头和植物配置数据可导出
- 极冷、荫蔽、碱土、缺水、低维护与低预算同时出现时生成多重风险提示

## 手工验收

在 Chromium 浏览器中完成以下检查：

1. 首页在桌面与手机视口下均可阅读，无水平溢出；
2. 切换三组预设后结果即时更新；
3. 调整面积、pH、水分、养护时间和预算时，数值显示同步刷新；
4. 每种植物可以展开六维匹配分；
5. CSV 能下载并以 UTF-8 正确显示中文；
6. 打印预览隐藏输入面板和导航，仅保留方案内容；
7. 刷新页面后恢复最近一次场地条件。

## 当前限制

- 未接入实时天气、土壤传感器或图片识别；
- 植物价格是场景估价，不是实时报价；
- 耐寒区只作为气候过滤的简化变量，不能替代露地极端最低温记录；
- 布局图为示意结构，不按实际场地坐标放样；
- 未完成多地区田间校准。

## 下一步实验设计

选择 3 个面积 8–30㎡ 的小场地，每个场地设置模型方案与园艺师方案两个对比组，连续记录 6 个月：

- 成活率与补植次数
- 每月实际开花植物数
- 单次养护工时
- 灌溉用水
- 病虫问题和倒伏情况
- 使用者满意度

用真实记录拟合物种与地区修正系数，再决定是否进入商业试点。
